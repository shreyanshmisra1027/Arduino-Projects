# Arduino Projects 🔌⚡

A collection of Arduino projects, experiments, and modules — ranging from beginner-friendly basics to more advanced electronics and sensor-based systems.

## 📌 About This Repository
This repository contains:
- Arduino sketches (`.ino`)
- Sensor interfacing examples
- Mini projects & demos
- Well-commented code for learning and experimentation

Each project is organized in its own folder with:
- Source code
- Circuit explanation
- Required components

## 🧰 Hardware & Software Used
- **Boards:** Arduino Uno R3 (for now)
- **IDE:** Arduino IDE
- **Simulation Software Used:** wokwi.com
- **Language:** Embedded C/C++
- **Common Components:**  
  - LEDs, Resistors  
  - Sensors (DHT11/DHT22, Ultrasonic, IR, etc.)  
  - Displays (LCD, OLED)  
  - Motors & Relays
